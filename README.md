# ReservarSalas
Sistema de Gestión de Reservas de Salas
Una solución eficiente y sencilla para la administración de espacios físicos, diseñada para facilitar el control de Aulas, Laboratorios y Auditorios. Este software permite gestionar el ciclo completo de una reserva, desde el registro de la sala hasta la generación de métricas de uso.

## Características Principales
El sistema ofrece un conjunto de herramientas robustas para la administración de espacios:

Gestión de Salas: Registro, edición y listado de espacios disponibles.

Control de Reservas: Crear, consultar y cancelar reservas de forma intuitiva.

Categorización: Clasificación automática por tipos de sala:
- Aula
- Laboratorio
- Auditorio

Reportes Inteligentes: Generación de un reporte general con estadísticas de ocupación y uso por tipo de sala.

## Guía de Uso
Una vez ejecutado el programa, podrás interactuar con las siguientes funcionalidades:

1. Registrar una Sala
Ingresa el nombre, la capacidad y selecciona el tipo (Aula, Laboratorio o Auditorio). El sistema validará que el ID de la sala sea único.

2. Crear una Reserva
Selecciona una sala disponible, ingresa los datos del usuario y el horario deseado. El sistema bloqueará automáticamente el espacio para evitar duplicidad de horarios.

3. Consultar y Listar
Listar Salas: Visualiza todos los espacios registrados y sus características.

Listar Reservas: Revisa el historial de todas las reservas activas y pasadas.

4. Cancelación
Permite liberar una sala previamente reservada ingresando el código de reserva, actualizando el estado de disponibilidad en tiempo real.

5. Reporte General
Accede a la opción de "Generar Reporte" para obtener un resumen detallado que incluye:

Total de reservas realizadas.

Desglose de uso por categorías (¿Se usan más los Laboratorios o las Aulas?).

Porcentaje de ocupación general.
